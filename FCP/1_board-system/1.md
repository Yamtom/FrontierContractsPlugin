## Як користуватися Board System

---

### 1. Що таке дошка

Board — це фізична конструкція у світі Minecraft. Без правильно збудованої структури дошка не активується і контракти не генеруються.

**Обов'язкові блоки:**

```
Вигляд спереду:

  [S] [S*] [S]   <- верхній ряд: 3 × OAK_PLANKS + wall signs
  [S]  [S]  [S]  <- нижній ряд: 3 × OAK_PLANKS + wall signs
        |
     [FENCE]     <- OAK_FENCE під центром нижнього ряду
```

- `[S*]` — Header Sign (верхній центральний): перший рядок повинен містити слово **contact**
- Решта 5 знаків — Task Signs (показують контракти)
- Bell-дзвін у радіусі **13 блоків** від дошки (за замовчуванням)
- Bell повинен належати до village-зони (поряд ліжко або job-site блок)

---

### 2. Встановити дошку (admin)

**Метод A — Автоматичне розміщення** (рекомендовано):
```
/contracts admin placeboard <id> <type> <назва...>
```
1. Стань перед місцем, де має бути дошка, і дивись на підлогу
2. Введи команду — плагін сам ставить всі блоки і реєструє дошку
3. `type`: `SETTLEMENT` або `CUSTOM`
4. `<назва...>` — відображуване ім'я (може бути з пробілами)

**Метод B — Ручна побудова + сканування:**
1. Побудуй структуру згідно з геометрією вище
2. На header sign (верхній центральний) напиши **contact** у першому рядку
3. Переконайся, що поряд є Bell у village-зоні
4. Дивись на будь-який блок конструкції і введи:
   ```
   /contracts admin scanboard <id> <type> <назва...>
   ```

---

### 3. Перевірити стан дошки (admin)

```
/contracts admin validateboard <id>
```
- Перевіряє всі блоки фізичної структури у реальному часі
- Якщо структура валідна — показує відстань до Bell
- Якщо зламана — виводить список конкретних помилок у чат

**Список дошок:**
```
/contracts admin board list
```

**Примусово оновити контракти на дошці:**
```
/contracts admin board refresh <id>
```

---

### 4. Взаємодія гравця з дошкою

| Дія | Результат |
|-----|-----------|
| **ПКМ** порожньою рукою | Відкриває GUI зі списком контрактів |
| **ПКМ** з предметами в руці | Здає предмети у відповідний активний контракт |
| **ЛКМ** | Нічого не відбувається |

> Якщо дошка зламана (блок видалений, sign змінений) — при взаємодії відобразиться повідомлення про помилку і GUI не відкриється.

---

### 5. Захист блоків дошки

- Гравці **без** `frontiercontracts.admin` **не можуть** ламати або змінювати знаки дошки
- При спробі — отримують повідомлення з `errors.board-protected`
- Адміни з `frontiercontracts.admin` можуть редагувати вільно

---

### 6. Адмін-команди Board System

| Команда | Опис |
|---|---|
| `/contracts admin placeboard <id> <type> <назва>` | Автоматично розмістити дошку |
| `/contracts admin scanboard <id> <type> <назва>` | Зареєструвати вручну збудовану дошку |
| `/contracts admin validateboard <id>` | Перевірити фізичну структуру |
| `/contracts admin board list` | Список всіх зареєстрованих дошок |
| `/contracts admin board refresh <id>` | Примусово перегенерувати контракти |
| `/contracts admin board reputation <player> <id>` | Репутація гравця на поселенні |
| `/contracts admin reload` | Перезавантажити конфіги без рестарту |

---

### 7. Налаштування у config.yml

```yaml
boards:
  bell-radius: 13.0          # максимальна відстань до Bell
  village-poi-radius: 32.0   # радіус пошуку village POI від Bell
  refresh-interval-seconds: 300  # інтервал автооновлення контрактів
```

> Дані самих дошок (координати, facing, bell) зберігаються у `boards.yml` — **не редагуй вручну**.

---

### 8. Дозволи

| Permission | Default | Опис |
|---|---|---|
| `frontiercontracts.use` | all | Взаємодія з дошками, отримання контрактів |
| `frontiercontracts.admin` | op | Всі адмін-команди, обхід захисту блоків |
