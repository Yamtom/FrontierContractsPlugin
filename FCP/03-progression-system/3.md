## Як користуватися Progression System

---

### 1. Три рівні прогресії

```
PlayerStats             — XP та рівень гравця (глобально)
SettlementReputation    — Репутація гравця на конкретній дошці (per-board)
SettlementProgress      — Прогрес самого поселення (trust + project unlock)
```

---

### 2. Рівень гравця (XP / Level)

**XP нараховується за кожен завершений контракт** залежно від рангу:

| Ранг | Base XP |
|------|---------|
| F    | 50      |
| E    | 100     |
| D    | 250     |
| C    | 600     |
| B    | 1200    |
| A    | 2500    |
| S    | 5000    |

**Формула рівня — квадратична** (інспіровано AuraSkills):

```
step(L) = xp-multiplier × (L-1)² + xp-base   (для рівня L ≥ 2)
cumulativeXP(L) = step(2) + step(3) + ... + step(L)
```

З дефолтними значеннями (`xp-multiplier: 100`, `xp-base: 200`):
- Рівень 2 → потрібно 300 XP
- Рівень 5 → ~1 200 XP
- Рівень 10 → ~5 700 XP
- Рівень 20 → ~50 000 XP

**Максимальний рівень:** 20 (конфіг `max-level`)

---

### 3. Prestige (Ветеранський бонус)

Досягнувши **рівня 20**, гравець може перейти в Prestige:

```
/contracts prestige
```

**Що відбувається:**
- XP скидається до 0 (рівень стає 1)
- `prestigeLevel` збільшується на 1
- Гравець отримує **постійний бонус +5% XP** за кожен рівень prestige

| Prestige | XP-множник |
|----------|------------|
| 0 (без prestige) | ×1.00 |
| 1 | ×1.05 |
| 2 | ×1.10 |
| 3 | ×1.15 |
| 4 | ×1.20 |
| 5 | ×1.25 |

**Максимум prestige:** 5 (конфіг `max-prestige`).

Коли гравець досягає рівня 20 — він отримує автоматичне сповіщення в чаті:
> `You have reached level 20! Use /contracts prestige to prestige.`

---

### 4. Pity System (Anti-Frustration)

Захищає від тривалих серій без рідкісних рангів. Лічильники зберігаються **per-board** у `SettlementProgress`.

```
Після кожного контракту → rankedWithoutHigh++, rankedWithoutElite++

Якщо rankedWithoutHigh ≥ high-rank-pity-threshold (дефолт 12):
  → +12 до ваги рангів B/A/S при наступному roll

Якщо rankedWithoutElite ≥ elite-rank-pity-threshold (дефолт 25):
  → +8 до ваги рангів A/S при наступному roll

При випаданні B або вище → rankedWithoutHigh = 0
При випаданні A або вище → rankedWithoutElite = 0
```

---

### 5. Rank Roll Table

Ваги рангів залежать від **ефективного рівня генерації** поселення:

```
effectiveLevel = рівень найкращого гравця + trust_level ÷ trust-level-divisor
```

З конфігу `rank-roll-table`:

| Level | F  | E  | D  | C  | B  | A  | S  |
|-------|----|----|----|----|----|----|-----|
| 1     | 70 | 25 | 5  | 0  | 0  | 0  | 0  |
| 5     | 40 | 35 | 18 | 5  | 2  | 0  | 0  |
| 10    | 15 | 25 | 30 | 20 | 8  | 2  | 0  |
| 15    | 5  | 10 | 20 | 30 | 20 | 10 | 5  |
| 20    | 0  | 5  | 10 | 25 | 30 | 20 | 10 |

Проміжні рівні — лінійна інтерполяція між двома найближчими записами.

---

### 6. SettlementReputation (Репутація)

**Per-player, per-board** — у кожного гравця своя репутація на кожній дошці.

| Подія | Зміна репутації |
|-------|----------------|
| Виконано контракт | +10 (або значення `reputation` з rewards) |
| Відмова від контракту | −5 (конфіг `reputation-on-abandon`) |
| Прострочений контракт | −3 (конфіг `reputation-on-fail`) |

Репутація не може бути нижче 0. Поле `lifetimeCompleted` рахує **всі виконані** контракти на цій дошці незалежно від репутації.

Перегляд репутації гравця:
```
/contracts admin board reputation <player> <board_id>
```

---

### 7. SettlementProgress (Прогрес поселення)

**Per-board** — накопичується незалежно від конкретного гравця.

| Поле | Опис |
|------|------|
| `trust_level` | Рівень довіри (росте при виконанні контрактів) |
| `routine_completions` | Кількість рутинних контрактів виконано на дошці |
| `unlocked_projects` | JSON-масив розблокованих PROJECT ID |
| `active_project_id` | Поточний активний PROJECT (`null` якщо немає) |

**Trust нараховується** при кожному виконаному контракті:
```
trustGain = max(trustPerRoutine, reward.reputation)
```

---

### 8. Розблокування PROJECT-контрактів

PROJECT-контракт стає доступним, якщо:

```yaml
project-triggers:
  - project-id: "bridge_project"
    min-trust: 50
    min-routine-completions: 100
    cooldown-minutes: 1440
```

Умови: `trust_level ≥ minTrust` AND `routine_completions ≥ minRoutineCompletions` AND `now ≥ cooldown_until`.

Після виконання PROJECT:
- ID додається до `unlocked_projects`
- `active_project_id` скидається в `null`
- Запускається cooldown

---

### 9. Налаштування у contracts.yml

```yaml
progression:
  xp-multiplier: 100                 # коефіцієнт квадратичної формули (m)
  xp-base: 200                       # базовий крок (b)
  xp-per-level: 10                   # лінійний fallback (якщо xp-multiplier: 0)
  max-level: 20
  max-prestige: 5
  prestige-xp-bonus-per-level: 0.05  # +5% XP за кожен рівень prestige

contract-xp:
  F: 50
  E: 100
  D: 250
  C: 600
  B: 1200
  A: 2500
  S: 5000

anti-frustration:
  high-rank-pity-threshold: 12
  elite-rank-pity-threshold: 25
  high-rank-weight-bonus: 12
  elite-rank-weight-bonus: 8
  recent-variant-memory: 20
```
